# Mathmetry

PDF 기출과 손필기 사진을, 수식이 살아 있는 한글(.hwpx) 파일과 깔끔한 노트(.goodnotes)로 바꾸는 윈도 프로그램입니다.

- **한글 변환기**: PDF 기출 → 수식 살아 있는 한글 파일
- **손필기 변환기**: 손필기·노트 사진 → 깔끔한 해설 한글 파일·노트
- **양식 관리**: 한글 파일 양식 → 내 양식으로 등록·손보기

## 받기

[최신 버전 받기](https://github.com/kyijgnes/mathmetry/releases/latest)에서 `Mathmetry-설치-<버전>.exe` 를 받아 실행합니다.

- 관리자 권한 없이 설치됩니다.
- 코드 서명을 하지 않아, 처음 실행할 때 「Windows의 PC 보호」 창이 뜰 수 있습니다. 「추가 정보」 → 「실행」을 누르면 됩니다.
- 새 버전이 나오면 프로그램 홈에 「새 버전」 표시가 뜹니다.

## 준비물

- Anthropic API 키: [Anthropic 콘솔](https://console.anthropic.com/)에서 만듭니다. 읽기에 드는 AI 비용은 그 키의 계정으로 청구됩니다.
- 키 없이도 「예시 결과」로 화면을 둘러볼 수 있습니다.
- 한글 프로그램이 없어도 한글 파일을 만들 수 있습니다.

## 자료 처리

- 넣은 파일은 읽기 위해 Anthropic 서버로 보내집니다.
- 키와 작업 자료는 이 PC 의 `%LOCALAPPDATA%\Mathmetry\` 에, 완성한 결과는 `내 문서\Mathmetry\` 에 저장됩니다.
- 프로그램을 지울 때 내 자료를 같이 지울지 한 번 묻습니다. 결과 저장 자리의 파일은 남습니다.
